# 集画 (Jihua Platform)

《集画》:面向二次元轻量级内容创作者的一站式ai辅助创作与约稿平台。
本项目是参加第九届传智杯的参赛作品。

## 核心功能亮点

1. 线稿缺口检测：在 Canvas 画板中导入线稿，系统能自动扫描未闭合的断点，并用红圈高亮显示，辅助画师快速排查漏线。
2. 简单辑：输入灵感，模拟AI生成分镜脚本，提供动效教程悬浮窗；内置canvas时间轴轨道，点击“一键生成草稿”可自动将图片按脚本排入轨道，支持手动拖拽调整。
3. live模式（前端高保真演示）：通过上传立绘，模拟进度，图层勾选显示/隐藏，直观演示拆件效果。
4. 多场景防逃单机制：针对板绘（虚拟），手绘包本（实体），周边定制（制造）三种场景，分别设计了细分的交易进度条节点。
   
## 技术与开发模式

技术栈：HTML5 / CSS3 / Vanilla JavaScript (原生 Canvas 图像处理)。
AI 辅助开发：本项目全程使用 Trae IDE 进行 Vibe Coding。
过程留痕：完整保留了核心功能的 Prompt 迭代记录，以及 6 次细粒度的 Git 提交历史，确保开发过程真实可复现。
