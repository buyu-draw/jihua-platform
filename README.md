# 集画 (Jihua Platform)

《集画》:面向二次元轻量级内容创作者的一站式ai辅助创作与约稿平台。
本项目是参加第九届传智杯的参赛作品。

## 核心功能亮点

1. 线稿缺口检测：在 Canvas 画板中导入线稿，系统能自动扫描未闭合的断点，并用红圈高亮显示，辅助画师快速排查漏线。
2. 手书/live2d模式：手书动画预览，live2D拆件引导。一条从线稿到成片的引导式”工作流“路径，提高工作效率，降低入门门槛。
3. 防逃单担保交易机制：设计了资金托管、分阶段交付（草图-线稿-成图）的交互界面，以及防盗图水印保护，直击约稿市场的信任痛点。
4. 多身份权限面板：支持创作者（画师）、实验家（商家）、探索者（买家）三种身份切换。

## 技术与开发模式

技术栈：HTML5 / CSS3 / Vanilla JavaScript (原生 Canvas 图像处理)。
AI 辅助开发：本项目全程使用 Trae IDE 进行 Vibe Coding。
过程留痕：完整保留了核心功能的 Prompt 迭代记录，以及 5 次细粒度的 Git 提交历史，确保开发过程真实可复现。

## 如何快速预览

本项目无需配置复杂的后端服务器。你只需要将仓库代码下载到本地，直接用浏览器双击打开 index.html 文件即可体验所有交互。
